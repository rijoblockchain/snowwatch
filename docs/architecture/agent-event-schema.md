# Agent Event Schema

## Purpose
`AGENT_EVENT_LOGS` is the runtime telemetry table for SnowWatch.

It captures operational events generated by business/runtime agents and provides the base dataset for:
- AI incident enrichment
- latency analysis
- dependency-aware observability
- remediation recommendations

## Design Principles
- include both machine-readable context and raw evidence
- support downstream dependency tracing
- support future governance and access reasoning
- keep schema flexible enough for simulation and extension
