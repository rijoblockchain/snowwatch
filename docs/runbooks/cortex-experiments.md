# Cortex Experiments

## Objective
Evaluate how Snowflake Cortex can interpret raw observability logs.

## Experiments
1. Summarization
2. Issue classification
3. Root-cause diagnosis

## Key observations
- Summarization gives concise human-readable descriptions
- Classification is useful for KPI grouping
- Diagnosis is useful for operator guidance
- Output format is still free-form and needs structuring for production use
