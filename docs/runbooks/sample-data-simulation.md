# SnowWatch Sample Data Simulation

## Purpose
This sample data makes SnowWatch behave like a realistic agent observability prototype.

## Included data
- Agent metadata in AGENT_REGISTRY
- Logical agent relationships in AGENT_DEPENDENCIES
- Runtime telemetry in AGENT_EVENT_LOGS

## Example scenarios represented
- Timeout failure
- Permission failure
- Data quality failure
- Upstream dependency failure
- Successful execution events
